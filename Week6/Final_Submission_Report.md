# Completed Projects

1. Heart Disease Prediction
- Collected and analyzed the heart disease dataset.
- Performed data cleaning and preprocessing.
- Trained and evaluated a machine learning model to predict the likelihood of heart disease.
- Measured model performance using appropriate evaluation metrics.

2. Customer Clustering
- Preprocessed customer data by handling missing values and removing duplicates.
- Standardized the dataset using feature scaling.
- Applied the K-Means clustering algorithm to segment customers into different groups.
- Used the Elbow Method and Silhouette Score to evaluate the clustering performance.
- Visualized customer clusters and generated a project report.
