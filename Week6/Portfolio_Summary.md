# Project 2: Customer Clustering

Objective

The aim of this project was to group customers with similar characteristics using machine learning. This helps businesses better understand customer behavior and create targeted strategies.
Dataset

Customer Data Dataset

Algorithm Used

- K-Means Clustering

 Results

- Successfully divided customers into meaningful clusters.
- Used the Elbow Method to determine the appropriate number of clusters.
- Evaluated clustering performance using the Silhouette Score and visualized the customer groups.

Skills Developed

- Data preprocessing
- Feature scaling using StandardScaler
- Unsupervised machine learning
- Cluster analysis and visualization
